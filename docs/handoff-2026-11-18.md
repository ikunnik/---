# 交接说明（2026-11-18）

> 接手前先读这一页，能省两三天。所有结论都带 文件:行号，可直接跳到代码核对。

## 0. 一句话

四足机器狗（Dobot X1）的 ROS2 视觉任务链：**停止线/红绿灯 → 掉头 → 盲道跟线**，
中间夹一个自动避障状态机。代码 = v7.5.0 基线 + 两次现场调参（commit `5df368f`、`cb54d45`）。
真机和完整测试**只能进 distrobox 容器**。

## 1. 系统边界（改代码前必须知道）

```
DDS 相机(camera0 RGB / camera2 RGB+深度)
  → workers/*_camera.py   独立进程，解码+检测
  → workers/*.py          线程，结果塞进 comm.Latest 白板
  → decisions/            纯逻辑：守卫 + 状态机；无 IO、无线程、不 import rclpy/cv2/grpc
  → actions.py            唯一动作目录，产出 ActionRequest
  → workers/executor.py    唯一执行者，generation 版本号防过期指令 + 看门狗
  → motion/               ros2 = /planner/vel_cmd Twist 20Hz；sdk = gRPC 50051
```

铁律（破一条就出线上问题）：

1. **只有决策层发运动**；`workers/`、`motion/` 不许自己决定速度。
2. **只有 MotionExecutor 碰后端**，别在别处 publish Twist。
3. 决策层保持纯函数式，否则测试全废。
4. 新增任何运动 kind，必须同步改 `decisions/avoidance/pending.py:53 _pending_safety_veto`
   与 `decisions/engine.py` 的动作跟踪，否则动作期间不看感知 = 盲走。

| 位置 | 职责 |
|---|---|
| `main.py` / `runtime/assembly.py` | 进程线程装配，按模式选 worker |
| `app/cli.py` / `rover_x1/settings.py` | 命令行与 ROS 参数校验 |
| `config.py` | **唯一参数来源**；`config/rover.yaml` 是生成物 |
| `workers/executor.py` | 单一执行器 + 循环速度看门狗 |
| `decisions/engine.py` | 总入口：避障/盲道/停止线三选一 |
| `decisions/avoidance/` | 避障状态机 go/hold/plan/bypass/navigation/pending/transitions/path_return |
| `decisions/traffic/` | 停止线序列 line/align/signal/pass/core |
| `decisions/lane.py` | 盲道 PD 跟线 |
| `motion/ros2_backend.py` | Twist 实时运动 + 里程计；`_run_rotation` / `_run_line` |
| `motion/posture_sdk.py` | 只为起立/切步态/读姿态而活的 SDK 适配 |
| `tools/` | 探针与回归；`tools/check.sh` 是最小门禁 |

## 3. 已经改好的（commit `cb54d45`）

### 3.1 盲道跟线走斜 —— 已修

现象：能小幅微调，但一直歪着 5~10° 沿线走，偶尔顿一下。

根因（三条叠加，都量化过）：

1. `lane_loop_update_threshold = 0.12 rad/s` 拿转向指令比，而指令满量程只有 ±0.18：
   0.12 相当于**横向 33cm 或航向 10° 的死区**，小于它的偏差永远不纠。
2. `lane_loop_min_update_s = 2.5s`：0.4m/s 下**每米才更新一次转向**，中间纯开环。
3. `lane_cross_deadband = 0.018` 单独就允许约 6.8° 航向偏；且限跳/EMA 按 50Hz tick 算，
   8FPS 的同一帧被重复积分 → 滤波等于没做。

改法（`decisions/lane.py:138 _track`、`:159 _control`、`config.py:69-77`）：按检测帧
（`lane.ts`）更新滤波与微分；限速对象从内部累加值改为**已下发值**；阈值 `0.02`、
最小间隔 `0.22s`、死区 `0.008`、`filter_alpha 0.5`、`yaw_accel_limit 0.30`。

验证：`tools/lane_sim.py`（用**真实 LaneFollower** + 运动学植物 + 8FPS 噪声的闭环仿真）。
改前→改后：航向 rms 5.3°→1.9°，航向>5° 时间占比 41%→7%，横偏 rms 4.6cm→2.3cm。
`python3 tools/lane_sim.py --old-tuning` 可复现对比。

### 3.2 绕障「两侧都试完就停车」—— 已修

现象：障碍只在右边、左边 1.27m 空着，左右看过后却锁定停车（语音「左右两侧空间不足」）。

根因：中心距离取 ROI 内**最近 5% 像素**（为细杆设计）。0.45m 宽的牌在 0.66m 处张角约 35°，
固定 40° 转完后牌边仍压在 ±21° 中心锥体上（约 2° 残余），`_safe_step` 永远算出 0；旧逻辑
一次净空不足就把该侧写进 `tried_angles` 并回正，两侧试完 → 锁定。

改法：`decisions/avoidance/navigation.py:159 _escalate_bypass_angle`，在 `_replan` 最前面调用。
斜向段起点净空不足且**一步都没走**时，同侧追加 `bypass_angle_step_deg=15°`（上限
`bypass_angle_max_deg=75°`）；横向目标不变、转角越陡斜向段越短，所以不会越绕越远；到上限
才把该侧记成已试。回归：`tools/test_bypass_angle.py`（4 条，按现场日志数字复现）。

### 3.3 停止线「绿灯也停」—— 已修

刻意延时是**串行**四段：`stop_settle_s` → 对齐（最多 2 次，每次之后又等一次停稳）→ 对齐
全部结束才 `traffic_active.set()` 开红绿灯识别 → 还要 `confirm_frames=4` + `confirm_s=0.3`
重新投票。最坏 2.5~4s 的「绿灯但不动」。

改法：`decisions/traffic/line.py:24` 到线即刻开红绿灯识别（与停稳/对齐并行）；
`decisions/traffic/align.py:18` 只有第一次真停稳需要等；`stop_line_align_max_attempts: 2→1`。
新时间线约 0.3~1.8s。回归：`tools/test_stop_line_align.py` 新增 3 条。

### 3.4 转身平滑 —— 只解决一半，见第 4 节

## 4. 未解决：避障转身又慢又拖腿（优先）

现象：避障转身 40° 约 1.4s，**拖腿、前脚交叉、胸腔下沉**。

已试三种做法与实测（`motion/ros2_backend.py:335 _turn_rate`、`:352 _run_rotation`）：

| 做法 | 结果 |
|---|---|
| `ω=1.0` 阶跃、到位直接切 0 | 40° 只用 0.7s，但**只够 2 个步态周期**（0.3s/周期）→ 拖腿交叉；起停两次冲击 |
| `ω=0.5` + 按剩余角减速到 0 | **卡死**：底盘原地转身有最小可行转速（约 0.75~0.8），指令降到它以下就不迈步；剩余角不再变小 → 指令永远卡 0.4 → 40° 转 4.85s 差 7° 被 5s 超时打断 → 锁定（需重启） |
| 现在：`ω=0.8` + 0.3s 起转斜坡 + 到角度即停 + 停稳 0.2s + 实测闭环放大(1.5×) | 40° 约 1.4s、超调 ≤1°、不再卡死；**观感仍是慢 + 拖腿** |

**结论：根因不是曲线，是「只给纯 yaw 的 Twist」。** 四足原地转身必须迈步，只给角速度时
它只能靠四脚搓地/甩后躯，速度一慢就变成拖。软件层调曲线只能缓解，不能根治。

### A. 切厂商原生 rotation 动作（最可能根治，优先做 A/B）

管道**已经通了**，只是没用：`robot_link.py:137 _add_motion` + `:155 build_request` 已支持
`Motion("rotation", direction, angle)`；`motion/posture_sdk.py` 的 `SdkPosture._link` 现在就持有
一个活的 `RobotLink`（gRPC 50051）。厂商的原地转身是专门调过的步态。

要做的：

1. `motion/posture_sdk.py` 加 `turn(direction, angle)`：内部 `self._link.execute_stream(Motion(...))`，
   返回可迭代 call（`robot_link._GrpcMotionCall` 已支持 `cancel()`）。
2. `_run_rotation` 加分支：`cfg.ros2_turn_backend == "sdk"` 时走 SDK。
   **关键坑**：`_tick`（`motion/ros2_backend.py:206`）在 20Hz 持续发 Twist，会在 SDK 技能
   驱动底盘时打架 → 加 `_tick_paused` 标志，SDK 转身期间不发布。
3. `motion/dry_run.py` 补同样的分支，否则 `--dry-run` 漏测。
4. config 加 `ros2_turn_backend: str = "twist"`；yaml 用 `python3 tools/generate_ros_config.py`
   重生成（**别手改**）。
5. 验证：固定机位录 twist vs sdk 两段 40° 对比；日志打一行后端名。

### B. 分段转身（成本最低，观感改善明显）

`_run_rotation` 内部把角度切成 ≤15° 小段，每段末 `_set_target(0,0,0)` + `_wait(0.1~0.2s)`
再转下一段：等于「迈一步、落稳、再迈」。加 `ros2_turn_chunk_deg`、`ros2_turn_chunk_pause_s`
两个参数即可，不动决策逻辑。

### C. 边走边转（弧线）—— 观感最好但风险最高

1. 底盘有前向速度死区 `ros2_min_vx = 0.30`（`motion/ros2_backend.py:309` 会把小 vx 抬上去），
   40° 弧线会**顺带前进约 0.26m、横移约 0.09m**；
2. `decisions/avoidance/pending.py:53 _pending_safety_veto` 里 `turn` 只校验旋转净空，不校验
   前向净空 —— 弧线必须补，否则会一边「看两侧」一边往障碍凑；
3. `pending.py:94 _validate_action_result` 只看 yaw，不看位移，也要补。

建议只对**回正**（`Actions.turn(..., realign=True)`）用弧线，探测性转身保持原地。
注意后端只能看到 `Motion`、拿不到 kind，要区分得在 `Actions` 里加参数或换 motion_id。

### D. 步态/档位 + 减少转身次数

- `config.speed_ratio = 60`（10~100）是 SDK 速度档位，接机时传给 `SdkPosture`；
  原地转身在低档位可能更稳，值得 40/60/80 各录一段。
- 现在一次绕障要原地转 2~3 次（转 40° → 走 → 回正 40°，最坏还有追加的 15°）。
  可选：回正只在航向偏差大于约 20° 时做，其余交给 `path_return` 横向回线。

### 量化「好不好看」（别只靠眼睛）

`motion/ros2_backend.py:248 _on_odom` 拿的是完整四元数，现在只取了 yaw。把 **roll/pitch 也
解出来、只在转身期间打点**，看峰峰值 —— 这是身体摇摆的代理指标；再配固定机位录像做前后对比。
有了它，后面调参才有回归依据。

## 5. 其他待办与风险（按优先级）

1. `decisions/engine.py:19 LANE_HELP_DELAY_S = 10.0` 与 `tools/test_decisions.py` 里 2.1s 的断言
   不一致，那条测试一直红。要么改测试（读配置），要么定 2s 还是 10s。
2. `test_bypass_lateral` 的机身净空 0.28 vs 实测 0.2478：`body_half_width_m`/
   `bypass_side_clearance_m` 要现场实测标定，别拍脑袋调。
3. 盲道 `lane_center_ref = 0.5` 是**相机安装标定值**，换机器/换相机必须重标（历史取景实测
   过 0.510 / 0.758 / 0.438），否则会一直平行偏移着走。
4. `config/rover.yaml` 是 `tools/generate_ros_config.py` 的产物，`test_ros_package.py` 会校验
   漂移 —— 只改 `config.py` 再重生成。
5. `blocked_latched` 一旦置位**必须重启程序**；`turn_timeout`/`advance_failed`/`yaw_mismatch`
   都会锁存。改超时/校验前想清楚。
6. 执行器看门狗 `lane_loop_heartbeat_timeout_s`：决策线程停 1s 就取消循环速度并刹车；ROS2
   取消后若 0.15s 内没有新目标会补一帧零速（`ros2_cancel_zero_delay_s`）。盲道重发变密后
   若现场看到顿挫，先看这里。
7. 停止线检测器有几何门（PCA 伸长比/全宽行/倾角），见 `workers/stop_line.py` 与
   `assets/stop_line_profile.json`；改色域前先跑 `tools/stop_line_probe.py`。
