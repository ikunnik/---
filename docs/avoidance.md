# 整段绕障与返回原路线

默认启用，适用于普通避障及盲道模式的障碍接管。交通通过与掉头仍由各自控制器处理。

## 路线与完成条件

首次停车后保存 `entry_x / entry_y / entry_yaw`，定义一条世界坐标中的原始直线。
整个绕障事件内保持这个锚点；遇到第二个障碍也不另建一条偏移的路线。
横向偏差为 `-(x-entry_x)*sin(entry_yaw)+(y-entry_y)*cos(entry_yaw)`。

默认 `path_return_enabled=True`：只有横向误差≤0.12m、航向误差≤10°、感知和位姿新鲜、
前方距离≥1.0m时才报告完成。原位置缺失、位姿非有限数或过期、回切尝试耗尽均停车。
显式关闭 `path_return_enabled` 会允许仅回正航向；正常任务应保持默认开启。

## 局部规划

1. 等待不同相机帧形成稳定窗口；动态/接近中的障碍保持等待。
2. 首次选择满足侧向净空的较空侧，向该侧转45°；后续优先保持绕行侧。
3. 斜向目标0.8m，回正后沿原方向初始目标0.9m。各阶段净空足够时一次执行完整目标距离；前方保留 `max(danger_m, emergency_m)+safety_buffer_m` 的余量。
4. 转向后必须等新深度帧再决定能否前进。当前方向无净空时先回正并记住失败方向，再选另一侧。
5. 回切方向通过侧区检查后，先沿原方向实测前进0.4m确认越过拐角，再转向原线60°。
   侧区重新受阻、运动中断或重规划会清除确认记录。回线目标按实际剩余偏差、实际航向计算，不再按固定0.4m拆分。
6. 回切受阻则回正，继续沿障碍外侧前进，以 `min_bypass_advance_m`（当前0.9m）为目标，再观察回切空间；前方也受阻则再次绕行。
7. 回线后回正并检查前方；如果原线上还有障碍，保留原路线继续规划。

`navigation.py` 管理目标距离净空、位姿、实测进展与预算；`path_return.py` 管理回线；
`pending.py` 管理回执与运动中的安全守卫；`hold.py` 管理稳定窗口与最终完成条件。
`bypass_step_max_m` 仅为旧配置兼容保留，不再参与绕障控制。底层单次距离上限为3m；净空或回切目标上限不足时仍会缩短动作，完成后按实测剩余距离重新判断。

## 中断、失败与预算

- 距离动作中前方<0.7m：记录已走位移，取消动作，发送零速，等待匹配的停车成功回执。
  之后等待新帧和稳定窗口；不会将旧动作的取消回执误用于新计划。
- 前方<`emergency_m`、感知/位姿失效、动作失败/超时、实际进展不足或预算耗尽：锁存停车。
- 转身前和转身过程中都要求左/中/右数据有效且净空≥`rotate_clear_m`。
- 语音完成或超时后重新检查当前环境；旧转向计划不直接恢复执行。
- 距离超时复用 `Actions.move()`；ROS2 距离动作中里程计过期立即清零并失败。
- 总预算默认6m、24次距离动作、8次重规划、120s；回切最多6次，回正最多12次。
  路程累加各动作位移及停车确认期间的残余位移，不等同于高频轨迹弧长。
- 净空不足可在稳定安全后重新检查；执行故障和预算耗尽需重启或显式重置控制器。

## 离线验证

```bash
python3 tools/test_complex_avoidance.py
bash tools/check.sh
```

几何仿真以矩形障碍和三个前向射线扇区生成深度，逐拍积分动作并回传位姿。
覆盖左右绕行、非零原航向、长障碍、连续障碍、回切途中出现临时障碍、无路可走，
并验证原路线锚点不变、回线误差、目标距离、底层单次距离上限和路径的几何间隔。
故障测试覆盖回切急停、停车失败/超时、位置/深度过期、无进展、预算和语音后环境变化。
模拟后端也提供距离运动后的平面位置，供状态机和执行器集成测试使用。

## 能力边界

这是依赖前置深度与位置反馈的有界局部绕障，没有全局地图、障碍物跟踪或完整机身碰撞模型。
矩形仿真不能代替真机验证；窄通道、凹形陷阱、侧后方障碍可能导致停车，不能保证所有复杂场景都有可行路线。
回线精度依赖里程计；重定位或切换坐标系会使原路线失效。默认预算应根据实测路径、制动距离和场地调整。
`--vx` 只控制普通直行，绕障距离动作速度由 `ros2_line_vx` 控制；本次未执行真机运动。
